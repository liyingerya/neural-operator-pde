# Neural Operator for 2D Advection–Diffusion

A scientific machine learning project using a Fourier Neural Operator
to learn surrogate dynamics for a 2D advection–diffusion PDE.

## Goals

- Build and verify a 2D PDE solver
- Generate simulation data across varying physical parameters
- Implement a Fourier Neural Operator in PyTorch
- Compare neural surrogate predictions against the numerical solver
- Evaluate rollout stability and out-of-distribution generalization
- Benchmark inference speed on CPU/GPU
